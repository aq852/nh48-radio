# Add permanent songs

Put audio files in this `songs` folder, for example:

```text
songs/midnight-drive.mp3
songs/neon-mile.mp3
```

Then add each file to the `bundledTracks` list in `app.js` with its path, title, artist, and mood. Prefer MP3 files at 128-192 kbps for fast loading.

The **ADD MP3 SONGS** button on the live site lets each visitor choose songs from their device. Those selections stay private to that browser session and are not uploaded to the website.
